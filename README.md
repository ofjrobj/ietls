# IELT6.5 일반 웹페이지 v189

수정 내용
- v181-v183에서 들어간 반복형 자동 예문을 제거했습니다.
- 뜻이 있는 단어는 어떤 경우에도 덮어쓰지 않게 했습니다.
- 중복 단어 병합 시 기존 뜻, 기존 예문, 기존 품사, 기존 동의어를 우선 보존합니다.
- 브라우저 localStorage 단어장은 마이그레이션 전에 vocabBankBackupBeforeRecovery로 백업합니다.
- 외운 단어는 masteredVocabBank에 별도 저장하고, 오늘 단어와 남은 단어 선정에서 제외합니다.
- Vocabulary 상단 표시는 날짜, 오늘 단어 수, 남은 단어 수, 외운 단어 수만 보이게 했습니다. 다시 외울 단어는 있을 때만 표시됩니다.
- “문장 예문이 있는 학습 가능 단어” 문구는 사용하지 않습니다.
- 하이픈이 필요한 단어와 영국식/미국식 철자 병기를 유지합니다.

주의
- 실제 사전 기반 뜻과 예문이 없는 항목은 임의로 지어 넣지 않았습니다.
- 이전 파일에서 생성된 가짜 반복 예문은 앱 실행 시 localStorage에서도 제거됩니다.


## v185 수정 내용
- 2026-05-30 Vocabulary 오늘 단어 100개를 첨부 DOCX 단어장 내용으로 고정했습니다.
- 2026-05-30 단어 시험은 DOCX 100개에 사진 속 형광펜 단어 60개를 추가해 총 160개가 나오도록 수정했습니다.
- 사진 속 형광펜 단어만 추가했고, 체크 표시나 빨간 펜 표시만 있는 단어는 제외했습니다.
- 주요 뜻 오류를 수정했습니다. 예: vary는 ‘변하다, 달라지다’, valid는 ‘유효한, 타당한’, vision은 ‘전망, 시력, 비전’, violent는 ‘폭력적인, 격렬한’으로 반영했습니다.
- visualisation은 영국식 표기를 기본으로 두고, visualization도 시험 답으로 인정되도록 했습니다.
- well-behaved, worn-out처럼 하이픈이 필요한 단어는 하이픈 표기를 유지하고, 공백 입력도 시험에서 인정되도록 했습니다.
